# 論文角度盤點:x-coach 有哪些「不是套模型」的研究主線

寫作日期 2026-07-29。這份文件不是計畫書,是把**已經做完的實驗**重新讀一遍,
指認哪些東西構成可以投稿的貢獻、哪些還只是工程、哪些必須先補一個實驗才敢寫。

---

## 0. 先講結論:主線已經存在,只是散在 notes/ 裡

`project-overview.md` 寫的是一個**系統論文**:感知 + KG/RAG + LLM 生成 + 前端。
但過去兩個月實際做出來的東西,主軸完全不是那個。真正做出來的是這件事:

> **把這個領域沒有明講出來的預設拿出來,在「決策層」而不是「幾何層」,
> 用零參數對照去測它。**

四個預設,四次否證,都是自己的資料:

| 領域預設 | 實測結果 | 出處 |
|---|---|---|
| 關節誤差越低 → 教練判決越準 | **否證**。MAE 把模型排錯 2/3,排序保真度 `r` 排對 3/3 | `model_fusion_gate_results.md` |
| 3D 一定優於 2D | **否證為全稱命題**。深度/屈曲要 3D,外翻/額狀面校正後的 2D 更好 | `fit3d_decision_fidelity_summary.md` |
| 表徵無法「表達」X ⇒ 需要顯式 X 通道 | **四次否證**(軸向旋轉 / 器械 / 不確定度 / 融合) | `keypoint-blindspot-refutations` |
| 融合多個模型可降低誤差、進而提升偵測 | **否證**。四個 metric-3D 模型的帶符號誤差相關 0.55–0.78,犯同一個錯 | `model_fusion_gate_results.md` |

這個「先問領域在假設什麼,再用零參數對照打它」的動作本身就是方法論貢獻,
而且它天生不可能是「套用他人模型」——它是在檢驗別人模型被使用的方式。

以下 A–F 是這條主線的六個切面,依「新穎度 × 手上證據完成度」排序。

## A. 可解釋性強制了固定閾值,而固定閾值改寫了「什麼叫好的姿態估計」

**這是最強的一條,而且我認為是可以獨立成篇的。**

### 論證鏈

1. 姿態估計整個領域用 MPJPE / cue MAE 當目標,這是**量值損失**。
2. 但「可解釋」的教練回饋要求判準是**固定的、可引用的閾值**——
   「膝角未達 90° 即為深度不足(Hartmann 2013)」。閾值一旦學出來就沒有引文可引,
   也就沒有可解釋性。這不是實作選擇,是題目本身逼出來的約束。
3. 在固定閾值下,判決由**讀數的離散度相對於閾值的位置**決定,不由誤差量值決定。
4. 因此**最佳化 MPJPE 可以讓教練變差**。

### 已經量到的證據(全部在手)

- **收縮掃描 `shrinkage_sweep`(直接演示,不是相關性)**:把讀數做
  `x → mean + λ(x − mean)` 再重新對齊均值(**只動離散度,不動偏差**),掃 λ。
  **6/6 個 模型×動作 格子裡,MAE 最佳的 λ 嚴格小於判決最佳的 λ**;4/6 個格子 λ < 1.0,
  也就是 **MAE 實際在獎勵「把讀數壓扁」**。
  squat/NLF:λ 1.0 → 0.7 買到 **−19% MAE(4.63 → 3.73°),判決反而變差(flip 10.9% → 11.6%)**。
- **模型排序反轉**:MeTRAbs 在三個動作的旋轉不變膝角 MAE 全勝 NLF
  (6.37/7.43/4.59 vs 7.09/7.51/5.91),判決翻轉卻三戰全敗。
  對齊到同一取樣網格後**反轉倖存**(NLF@15 11.7/12.5/9.6 vs MeTRAbs 12.6/17.4/13.4)。
  兩個直覺機制都被否決:MeTRAbs 既沒有在極值幀上比較差,也沒有選錯幀——
  它 pooled / point@ext / extreme / frame_off 全部都贏。
  真正排對的是 Pearson `r`(3/3),MAE 排錯 2/3。

### 最漂亮的一點:自己的「負面結果」反而是這個理論的預測

Fitness-AQA 淺蹲那條線的結論是「深度通道是**冗餘**的」(`nlf_3d − nlf_2d = +0.003`, p=0.813),
和 Fit3D 的「深度決定一切」看似矛盾。但兩者的差別正好是**固定閾值 vs 學出來的分類器**:
單一特徵的 AUC 對正仿射變換是不變的,所以收縮效應在學習式判準下**必然消失**。
`fitness-aqa-depth-finding` 的備忘錄自己已經寫了這句話
(「under a *fixed threshold*, whereas a *trained classifier* absorbs residual 2D signal」),
只是沒把它升格成論點。這代表:**兩個資料集的結果不是互相打架,是同一個理論的兩個象限。**
這種「理論預測了自己的反例」的結構在審稿時非常有說服力。

### 缺什麼(寫之前必須補)

自己的 notes 已經誠實記下限制:`r` 與判決翻轉不是兩個獨立測量,判決本質上就是排序的閾值化版本。
收縮掃描把它從相關性升級成演示,但整條論證仍活在 mocap 量測空間裡,審稿人會說「這是解析的,不是實證的」。

**唯一該先跑的實驗(不需要新推論,特徵都在磁碟上):**
在 **Fitness-AQA consolidated Squat**(1623 影片、逐 fault 人類標籤、
nlf_3d / nlf_2d / mediapipe_2d / rtmpose_2d 四個 arm 的線索特徵已算好)上,
同一個線索、同一批 arm,跑兩種判準:
(a) **文獻固定閾值** → balanced accuracy;(b) **交叉驗證學出來的閾值** → balanced accuracy。

三個執行細節,錯一個實驗就沒意義:

- **閾值出處要先鎖死。** 整個主張的前提就是閾值可引用,所以它不能在這份資料上被調過,一次都不行。
  取自己 rule spec 裡的 Hartmann 2013 膝角 ≤ 90°,寫下來,然後才量。
  一旦因為某個 arm 看起來太差而回頭動閾值,這個條件就變成了學習閾值條件,對比整個垮掉。
- **標籤極性有坑。** `fitness-aqa-depth-finding` 記過:Fitness-AQA 淺蹲的 ReadMe 說
  「0=no error」,但實測與目視都顯示 class `1` 才是**蹲得比較深**的那一組(膝角 55° vs 86°),
  與資料夾名字相反。極性弄錯,固定閾值那一組會因為記帳理由讀成災難性錯誤。
- **預測先寫下來,不要事後補。**
  預測:**arm 之間的差距在 (a) 遠大於 (b)。**
  真正有意思的失敗是**兩邊差距都大**——那表示偵測器/深度品質不管用什麼判準都主導結果,
  「MAE 排錯模型」仍然成立,但「可解釋性強制了這個約束」這個框架就失去了咬合力。
  兩種結果都要能寫,所以先承諾。

(REHAB24-6 是唯一 Vicon GT 與人類標籤並存的地方,如果之後想把 MAE 與標籤準確率放進同一張表可以用它;
但它的標籤是整趟 rep 的二元正確性,不是「這個線索有沒有越過閾值」,而且 n=9 就是當初讓
`nlf-direct-3d` 停在 p=0.20 的那個功效地板。不要拿它當主證據。)

跑完才敢寫「這不只是 mocap 空間裡的算術」。

### 為什麼是原創

這是對**整個領域的目標函數**提出質疑,不是換一個 backbone。
兩份文獻回顧 PDF 都沒有碰到這個問題(見 §7)。

## B. 單目可觀測性:哪些錯誤在單一相機下根本判不出來

**證據很厚,但跨動作**沒有**複製成功——要當「開放問題」寫,不要當「規律」寫。**

### 已經量到的

- **視角腐蝕(n=160)**:投影 2D 膝角 MAE 42°、偏差 +41°;一個實測 78° 的深蹲底部,
  依相機不同讀成 108–133°。torso_lean(r=0.87)與 knee_width/外翻(MAE 0.02, r=0.90)則視角穩健。
- **誤差分解(這條最乾淨)**:把單目 2D 的線索誤差拆成
  *偵測器誤差(真實 2D − mocap 2D)+ 投影誤差(mocap 2D − GT 3D)*。
  膝角上真實 RTMPose 與**完美偵測器**差在 ±1° 以內(squat −0.70 / deadlift −0.28 / thruster +0.44)——
  也就是說整個 14–18° 全部是投影幾何,**再好的 2D 偵測器也救不了**。
  外翻正好相反:mocap-2D 讀得很準(0.04),誤差是真實偵測器加上去的(0.07–0.08)——
  **外翻要的是更好的 2D,不是 3D**。
- **決策層對應**:原始單目 2D 對好的深蹲**誤判 82%**;
  即使用 oracle 逐視角去偏,仍翻轉 16%(14% 假警報 + **42% 漏掉的淺蹲**,一個偏移量修不了兩種錯),
  NLF 3D 則是 7%(7% FA / 0% miss)。
- **成分是深度品質,不是骨架密度**:MediaPipe(稀疏 + 弱深度)只回收 ~20% 的線索,
  MeTRAbs(稀疏 + 真深度)達到 dense 模型水準,甚至是三個動作裡最好的膝角模型。

### 缺什麼

想把它寫成「線索軸與相機深度軸的夾角預測 3D 有沒有用」這種**可否證的規律**,目前只有**一個**正例:
squat 外翻(ΔAUC +0.080)。OHP 手肘不顯著,而且**已經量過並否證了視角這個解釋**
(mediolateral 深度分量 squat 與 OHP 都 ≈0.65,OHP 並沒有比較正面)。
所以機制故事目前是**死的**。誠實寫法是:提出可觀測性框架、給出量到的 needs-3D 地圖、
點名缺的資料(**側視角、以 mediolateral 錯誤為主的標註資料集**),當開放問題收尾。

## C. 表徵盲點的否證方法論(負面結果)

四個獨立實驗,同一個形狀:

| 盲點 | 素樸主張 | 為什麼垮掉 |
|---|---|---|
| A 節段軸向旋轉 | 三個點編不出 roll | 全身姿態把股骨扭轉預測到 **2.56–4.00° MAE** |
| B 器械 | 槓鈴不是身體部位 | 手**握著**它——**零參數**的定值偏移就定位得比任何調參模型好(3/4 格) |
| C 讀數可靠度 | 點估計沒有信心欄位 | 姿態自己預測自己的誤差比 NLF 的 `unc` 更準(14.16 vs 19.26 mm) |
| D 模型融合 | 合起來可以互補 | 帶符號誤差相關 0.55–0.78,去偏後融合在 **17/18 格輸給最佳單一模型** |

**可寫成論點的東西有兩個:**

1. **「表徵無法陳述 X」不蘊含「表徵未編碼 X」。**
   形如「R 不能表達 X ⇒ 顯式 X 通道必然帶來資訊」的論證不成立,而且**測起來很便宜**。
2. **零參數對照是必要的,不是保險。**
   四次裡有兩次的第一版結論是錯的,錯到跑了對照才發現:
   B 的初稿拿 3.00 cm 殘差去比 8.4 cm 的教練門檻,說「幾何那一半被否證」——
   那個比較**恆等函數也會通過**;A 用固定 ridge λ 憑空製造出一個 null(λ 調過之後 `femur_only` 是 +0.349)。
   還有兩個更精緻的陷阱值得單獨寫:**用 `L_HIP − R_HIP` 建正規化座標會把雙側資訊洩漏進
   號稱單側的特徵集**(oracle 骨盆座標下增益 +0.052 → +0.539);
   **全域逐欄置換不是 min-over-M 的有效虛無對照**,它同時破壞跨模型相依與共享幀難度。

這條當獨立論文不好賣,但當碩論的方法論章節、或投 workshop 的 negative-results track 很紮實。
它也是唯一能解釋「為什麼這份研究可信」的章節。

## D. 沉默的接地失效:RAGAS 這類指標結構上看不見的東西

**這條保住了原本的題目,而且是安全相關的。這是我認為第二該寫的。**

### 觀察

grounded generation 的評估(RAGAS faithfulness 等)問的是「產生的文字有沒有忠於檢索到的脈絡」。
它結構上看不見兩件事:

1. **檢索回傳了空的**——沒有脈絡,就沒有不忠於脈絡這回事。
2. **量測從來沒有發生**——沒有讀數,就沒有讀數被曲解這回事。

兩種情況下,系統都會產生**自信、流暢、而且 faithfulness 分數很高**的教練建議。
從輸出看,接地良好的建議和接地為空的建議**無法區分**。

### 這不是假想的,是這個 repo 的事故清單

- OHP 五個 `kg_query` 字串有 **3 個解析到空**,錯誤帶著空的成因/風險送到教練層。
- **三個 UI 介面**對「什麼都量不到」的影片顯示「clean rep」;`chat.py` 甚至叫 LLM 去恭喜使用者。
- 槓鈴抽取在深蹲上**靜默失敗**:RANSAC 鎖到背景器材(肩→槓 32–37 cm,物理上應該 10–15),
  而四視角平面殘差維持在 **2.1 mm**。
  → **自洽性指標抓不到一致的錯誤。** 對照組是 `clean_and_press`,它是**大聲**失敗的(閘門拒絕每一幀)。
  只有外部物理約束抓得到深蹲那一例。
- 這些**全部是 review 抓到的,沒有一個是測試抓到的,也沒有一個是 RAGAS 會抓到的**。

### 可以做成什麼

- 一個**接地失效的分類法**:空檢索 / 未量測 / 量到但用錯規則 / 靜默的感知失敗。
  最後一類特別值得寫:OHP 的有效性閘門只需要肩肘腕髖,深蹲影片全部有——
  所以**一段深蹲被當成 OHP 分析會「成功」,回報零個錯誤**,`wasMeasured()` 抓不到。
- 一個**可稽核的斷言格式**:每一句教練回饋綁定(量到的值、閾值、引文)三元組,
  可機器檢查而不需要人評。
- 一個**指標**:回應中可回溯到「這支影片實際量到的值」的比例——
  和 RAGAS faithfulness 並排量,展示兩者在事故案例上分歧。
- 修復模式已經有了:`wasMeasured()`、NaN 傳播(拒絕而非降級)、
  push-up 的 `required` 含腳踝所以裁到膝蓋就整段作廢。

### 為什麼是原創

XAI-for-AQA 現有工作大多在做 saliency map。這條講的是**接地的完整性**而不是**解釋的忠實度**,
而且是拿真實事故當證據。

## E. 棄權:一個會說「這個角度我量不出來」的教練

和 D 相鄰但可以分開。可寫的主張:**會棄權的教練在「與人類教練一致度」上勝過永遠回答的教練。**
手上已經有的機制:視角閘門、`wasMeasured()`、NaN 傳播、
push-up 的「拒絕而非降級」、觀測性標記(規則規格裡誠實標了 low/none 的那些)。

**尚未關閉的線索**:用跨模型歧異當棄權訊號。
`model-fusion-refutation` 說得很清楚:這條**需要的是難度訊號而不是互補性**,
所以誤差相關 0.55–0.78 並不會殺掉它——但它必須打敗那個殺掉 `unc` 的 51 特徵姿態預測器。
這是一個乾淨、範圍明確、成敗都能寫的實驗。

## F. 負載不可辨識性:唯一還活著的盲點

blind spot B 的**量值那一半沒有被否證**:相同的運動學加上未知的外部負載,
關節力矩在數學上就是不可辨識的。這是**真正的理論極限**,不是模型不夠好。

這台機器上沒有任何資料集有負載真值(Fit3D 全部人用同一根空槓;Fitness-AQA 標的是 fault;
REHAB24-6 沒有器械)。所以關掉它需要**力板 + 影片**的資料採集,那是決策不是分析工作。

寫法有兩種:(1) 當作範圍聲明——本系統對力矩類的宣稱明確棄權,並說明為什麼那是原則性的;
(2) 如果拿得到力板資料,這是一篇乾淨的論文。
另外 `data/Fitness-AQA/OHP/Unlabeled_Dataset/bar_trajectories_raw.zip` 有 **5490 條真實世界槓鈴軌跡**
標註沒用過,適合做外部效度,不適合做決策評估。

## 7. 三個必須誠實面對的落差

1. **計畫書的評估章節一項都沒跑。** 沒有 RAGAS 數字、沒有對人類裁判的 Spearman、沒有 user study。
   已經做的量測非常嚴謹,但它們回答的是**另一個問題**。這不是缺點,是**論文貢獻要重新宣告**的訊號。
2. **評分那條腿從來沒有建。** Spearman ρ 需要人類的**分級**評分,手上只有 fault 標籤與二元正確性。
   「錯誤偵測 + 解釋」本身是完整的貢獻——但這是要**明講的範圍決定**,不能默默不提。
3. **`docs/` 那兩份文獻回顧 PDF 不能當 novelty check。**
   `從量化分數到可信指導….pdf` 的參考文獻清單裡混了
   `bing.txt`、`words.txt`、debian.org 套件列表、以及一則叫
   "Navy Removal Scout 800 Pink Pill Assasin Expo Van" 的 scribd 文件。
   那是 LLM 生成時混進去的幻覺引用。
   **這件事本身有點反諷,但更重要的是它是風險**:題目就是在講幻覺,
   引用清單不能自己有幻覺。投稿前每一則引文都要像當初 movement-rule-detector 那樣逐條重驗
   (那次 subagent 產出過 3 個掰出來的作者字串,是靠 diff `paper_metadata` 抓到的)。

## 9. 論文 A 的骨架

**主張(一句話)**:可解釋的教練回饋要求可引用的固定閾值;固定閾值下,
教練判決跟隨讀數的**排序保真度**而非**誤差量值**;因此最佳化 MPJPE / cue MAE 可以讓教練變差。

**貢獻**

1. 指認姿態估計評估與下游教練決策之間的**目標錯配**,並說明它是**可解釋性本身**逼出來的,
   不是實作疏忽——閾值一旦學出來就沒有引文可引。
2. 把它從相關性**演示**成因果:收縮掃描只動離散度、不動偏差,
   6/6 個 模型×動作 格子裡 MAE 最佳的 λ 嚴格小於判決最佳的 λ。
3. **統一兩個看似矛盾的實證結果**:Fit3D 的「深度決定判決」與 Fitness-AQA 的「深度冗餘」
   是同一理論的兩個象限(固定閾值 vs 學習判準),不是互相打架。
4. **外部驗證**:在人類標籤上做固定 vs 學習閾值對照,證明主張不只活在 mocap 量測空間。
5. 實務結論:融合/估計器的目標函數應該最大化排序保真度,不是最小化 MPJPE。
   附帶推論——**這解釋了為什麼平均式融合會失敗**(17/18 格輸),它最佳化的正是錯的那個量。
