# Scripts

Runnable entry points are grouped by workflow:

- `pose/` - pose extraction, pose features, view estimation, rule detection, and pose-backend comparisons.
- `video/` - VideoMAE feature extraction, classifier training, experiment grids, and classifier error analysis.
- `knowledge/` - document ingestion, local RAG, knowledge graph cleanup, auditing, and querying.
- `rehab24/` - REHAB24-6 manifest building, skeleton features, correctness classifier, and Colab export.

See each subdirectory README for command examples.
